# BorderMC Ice Map Data

The official, open-source data repository for the BorderMC ice road network.

This repository contains information about ice road companies, stations, junctions, interchanges, elevators and highway lines.

## Network Data

The network is stored in `data/network.v1.json` and follows the JSON Schema defined in `schemas/network.v1.schema.json`.

### Companies

Organizations responsible for operating ice highway lines.

### Stations

Locations throughout the network, categorized as:

- `station` — A destination where players can enter or exit the network.
- `junction` — A point where an ice road splits into multiple directions.
- `interchange` — A connection between different ice highway lines.
- `elevator` — A transition between different Y-levels.

### Lines

Each line references an operating company, connected stations, and a series of coordinates defining its path.

## Data Validation

All contributions are validated automatically through GitHub Actions.

Validation includes JSON Schema compliance, unique IDs, and valid references between entities.

Invalid submissions cannot be merged when the repository's required checks are enforced.

## Audit History

Changes to the network are automatically recorded in `data/audit.v1.jsonl`.

The audit log tracks created, updated, and deleted entities.

Audit entries are generated by GitHub Actions and should not be edited manually.
